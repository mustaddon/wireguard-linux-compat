# Custom WireGuard for Linux 3.10 - x.x

## Driver install script 
```bash
wget --no-cache -O wgp-install.sh https://raw.githubusercontent.com/mustaddon/wireguard-linux-compat/refs/heads/test5/kernel-tree-scripts/install.sh
sudo bash wgp-install.sh
```

## Server setup script 
```bash
wget --no-cache -O wg-server.sh https://raw.githubusercontent.com/mustaddon/wireguard-linux-compat/refs/heads/test5/kernel-tree-scripts/server.sh
sudo bash wg-server.sh
```
